生成AIに「うまく答えてもらえない」ときは、ほとんどの場合**指示文（プロンプト）の情報不足**が原因です。この記事では、ChatGPT・Claude・Geminiのどれでもそのまま使えるプロンプトを10個まとめました。`【】`の部分を書き換えて使ってください。

## うまくいくプロンプトの3つのコツ

1. **役割を与える**：「あなたは経験10年の営業マネージャーです」
2. **目的と読み手を書く**：「取引先の部長に送る、お詫びのメール」
3. **出力の形を指定する**：「300字以内」「箇条書きで3つ」「表にして」

## 1. ビジネスメールを書く

```
あなたはビジネス文書に詳しいアシスタントです。
以下の内容で、【取引先の担当者】に送るメールを書いてください。
・目的：【打ち合わせ日程の変更をお願いしたい】
・伝えたいこと：【10/5→10/8以降に変更したい、理由は社内調整】
・トーン：丁寧だが堅すぎない
・長さ：200〜300字
件名も3案出してください。
```

## 2. 議事録を要約する

```
以下は会議のメモです。次の形式で整理してください。
1. 決まったこと（箇条書き）
2. 担当者と期限つきのToDo（表形式）
3. 次回までの確認事項
メモ：
【ここにメモを貼る】
```

## 3. 長い資料を3行で要約する

```
以下の文章を、忙しい上司が30秒で読めるように3行で要約してください。
最後に「判断が必要な点」があれば1行で追加してください。
【文章を貼る】
```

## 4. 企画のアイデアを出す

```
あなたは【業界名】のマーケティング担当です。
【ターゲット：30代の共働き世帯】向けに、【商品/サービス】の販促アイデアを10個出してください。
それぞれ「概要」「かかるコスト感（小・中・大）」「期待できる効果」を表にしてください。
```

## 5. 文章を読みやすく直す

```
以下の文章を、意味を変えずに読みやすく直してください。
・一文を短く
・専門用語はかんたんな言葉に
・修正した箇所と理由を最後に箇条書きで
【文章を貼る】
```

## 6. Excel・スプレッドシートの関数を作る

```
Googleスプレッドシートで、A列に日付、B列に売上が入っています。
月ごとの売上合計を別シートに出す方法を、関数と手順で教えてください。
初心者なので、どのセルに何を入力するか具体的にお願いします。
```

## 7. プレゼンの構成を作る

```
【社内の役員会】で【新しい業務ツールの導入】を提案する10分のプレゼンを作ります。
スライド8枚分の構成案を、各スライドの「タイトル」「伝えること」「入れるとよい図や数字」で出してください。
```

## 8. 反論・リスクを洗い出す

```
以下の提案に対して、慎重派の上司が言いそうな反論やリスクを5つ挙げ、
それぞれへの回答案も書いてください。
【提案内容】
```

## 9. 苦手な相手への返信を考える

```
以下のメールに返信したいです。相手は【少し感情的になっている顧客】です。
事実を認めつつ、こちらの立場も伝える返信を2パターン（やわらかめ／きっぱりめ）で書いてください。
【受け取ったメール】
```

## 10. 新しい分野を短時間で学ぶ

```
私は【経理】の仕事をしていて、【インボイス制度】について上司に説明する必要があります。
中学生にもわかる言葉で、
1. 一言でいうと何か
2. 自分の仕事に関係するポイント3つ
3. よくある誤解
の順に説明してください。最後に、公式情報を確認すべき点も教えてください。
```

## 注意：AIの答えは「下書き」として扱う

AIの回答は便利ですが、数字や固有名詞、法律に関わる内容は間違えることがあります。**最終チェックは必ず自分で**行い、社外秘や個人情報は入力しないようにしましょう。
